## 2. 교수 피드백에 대한 핵심 보완점

기존 발표에서 빠졌던 부분은 "무엇이 문제인가"와 "왜 지금 이 문제를 해결해야 하는가"를 먼저 말하지 않았다는 점이다. 이번 보고서와 구술 설명에서는 다음 순서로 설명하는 것이 적절하다.

1. 실시간 비디오 전송에서는 모든 프레임을 동일하게 취급하면 중요한 프레임이 늦어질 수 있다.
2. 중요한 I/P 프레임의 deadline miss는 단일 프레임 지연에 그치지 않고 GOP 전체 복호와 체감 품질 저하로 이어진다.
3. 따라서 콘텐츠 중요도와 전송 행동을 분리해서 볼 것이 아니라, 함께 결정하는 cross-layer 적응 전송이 필요하다.
4. 본 연구는 그 구조를 현재 heuristic 기반으로 구현했고, 중간 단계 실험에서 기준 정책보다 `late_frame_ratio`를 줄였다는 점을 보여준다.

## 3. abstract에 반드시 들어가야 할 문장 요소

요약과 ABSTRACT에는 아래 네 가지가 빠지지 않아야 한다.

- 연구 목적: 중요한 프레임의 deadline miss를 줄여 실시간 비디오 QoE를 개선하는 것
- 문제 배경: 모든 프레임을 동일하게 전송하면 전송 자원이 비효율적으로 쓰인다는 점
- 현재 방법: Stage A 중요도 산정 + Stage B 전송 행동 선택 구조
- 현재 결과: `heuristic_baseline` 대비 `frame_action_single_path`, `frame_action_multipath`가 더 낮은 `late_frame_ratio`를 보였다는 점

## 4. 현재 구현 범위를 기준으로 한 표현 원칙

- 가능: heuristic 중요도 산정, frame-level action selection, single-path/multipath 비교, 13개 공개 비디오 기반 중간 실험 결과
- 가능하지만 신중히 표현: ML 확장 인터페이스 존재, cross-layer queue-aware rule 존재
- 직접 주장 금지: 실제 QUIC multipath 구현 완료, RL 학습 완료, VMAF/SSIM 기반 최종 품질 검증 완료

## 5. 발표용 한 문장 정리

본 연구는 단순 TCP batching 최적화가 아니라, H.264 프레임 중요도와 전송 행동을 함께 결정하여 중요한 프레임의 deadline miss를 줄이려는 콘텐츠 중요도 기반 cross-layer 적응 전송 연구이다.
