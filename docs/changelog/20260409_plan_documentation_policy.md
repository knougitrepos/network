# 20260409 plan_documentation_policy

## 배경

- after-mid 브랜치에서 plan으로 수립한 계획을 별도 문서로 누적 관리할 필요가 생겼다.

## 변경 내용

- `docs/plan/` 폴더를 추가했다.
- `docs/plan/20260409_after_mid_reset_and_mininet_actual_experiment_plan.md` 파일로 현재 기준 계획을 기록했다.
- `AGENTS.md`에 앞으로 모든 계획 문서를 `docs/plan/YYYYMMDD_플랜제목.md` 형식으로 남기도록 규칙을 추가했다.
- `README.md`의 문서 구조 설명에 `docs/plan/`을 반영했다.

## 검증

- 계획 문서가 `docs/plan/` 아래 생성되었는지 확인했다.
- `AGENTS.md`와 `README.md`의 문서 구조 설명이 일치하는지 확인했다.
